### 核心组件

| 组件 | 技术 | 职责 |
|------|------|------|
| **novel-os-mcp** | Python + fastmcp | 中央 MCP 服务器，提供所有核心工具 API |
| **novel-os-web** | Python HTTP + HTML/JS | Web 管理控制台，支持中英文 |
| **novel-os-local** | Python CLI | 本地写作工具，连接 MCP 执行大纲/草稿/审核 |
| **PostgreSQL** | pgvector:pg16 | 主数据库，存储结构化数据和全文搜索 |
| **Qdrant** | 向量数据库 | 存储记忆片段的向量索引，支持语义搜索 |
| **Redis** | 缓存 | 缓存和会话管理 |

### 功能模块（11个核心模块）

1. **Admin** - 系统健康检查
2. **Auth** - 用户认证和 API Token 管理
3. **Workspace & Project** - 多用户工作区和小说项目管理
4. **Canon Documents** - 小说设定文档（世界观、力量体系、人物基线等），带版本控制
5. **Rules** - 规则系统（风格规则、一致性规则），支持作用域和生命周期管理
6. **Compliance** - 合规检查（敏感内容检测）
7. **Plot** - 情节管理（卷、章节计划、剧情线、伏笔）
8. **Memory** - 记忆系统（向量搜索、状态快照）
9. **State** - 实体状态管理（人物、势力、地点、物品及关系）
10. **Workflow** - 工作流（章节上下文准备、提交）
11. **Review** - AI 审核系统（审查报告、修订任务、学习提取）

### 部署架构

使用 **Docker Compose** 部署，包含以下服务：

| 服务 | 容器名 | 镜像 | 默认端口 |
|------|--------|------|---------|
| PostgreSQL | `novel-postgres` | `pgvector/pgvector:pg16` | 5432 |
| Qdrant | `novel-qdrant` | `qdrant/qdrant:latest` | 6333/6334 |
| Adminer | `novel-adminer` | `adminer:latest` | 8080（可选） |
| novel-os-mcp | `novel-os-mcp` | 自建镜像 | 8787 |
| novel-os-web | `novel-os-web` | 自建镜像 | 8790 |

Compose 文件位置：
- [docker-compose.yml](file:///d:/Project/novels%20codex/deploy/nas/docker-compose.yml) — 基础服务（PostgreSQL、Qdrant）
- [docker-compose.app.example.yml](file:///d:/Project/novels%20codex/deploy/nas/docker-compose.app.example.yml) — 应用服务（MCP、Web）

---

### 关键部署命令

**启动全部服务：**
```sh
cd /opt/novel-os
docker compose -f docker-compose.yml -f docker-compose.app.example.yml up -d
```

**重建 MCP：**
```sh
cd /opt/novel-os
docker compose -f docker-compose.yml -f docker-compose.app.example.yml up -d --build novel-os-mcp
```

**应用 SQL 迁移：**
```sh
cd /opt/novel-os
sh scripts/apply-schema.sh
```

**健康检查：**
```sh
cd /opt/novel-os
sh scripts/health-check.sh
```

**备份：**
```sh
cd /opt/novel-os
sh ./scripts/backup-all.sh
```
